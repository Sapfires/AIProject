## Содержание упражнений

### Pathfinder
1. Враг (Agent) ходит по маршруту патруля (PatrolPath), путь рисуется линией (LineRenderer).
2. Игрок двигается по клику мыши (указатель NicePointer), камера следует за игроком (NiceCamera).
3. У врага есть поле зрения (PointOfView).
4. Обнаружение игрока через коллайдер (COLIDER prefab + Detection.cs, OnCollisionEnter).
5. Обнаружив игрока, враг гонится за ним (`SetGoalMoveHere(player.position)`).

В методичке используется пакет K-PathFinder (github.com/synoise/Ai-in-Games, Unity 2022.3).
Его можно заменить своей реализацией A*: это засчитывается как own invention.

### Swarm control
Стая (boids): cohesion, separation, alignment. Желательно добавить обход препятствий и хищника.

### Machine Learning
Агент на Unity ML-Agents (например, RollerBall): обучение PPO через `mlagents-learn`, затем инференс обученной модели в Unity.

## Шаги

1. **Проект.** Создать проект Unity 6 (URP), подключить Unity MCP, выполнить `git init` с Unity `.gitignore`.
2. **Pathfinder.**
   - Сцена с уровнем: стены, пол, препятствия.
   - A*: сетка, алгоритм, heap, очередь запросов.
   - Упражнения 1–5; каждое отдельным коммитом.
3. **Swarm.** Сцена стаи с препятствиями, хищником и HUD со статистикой. Коммит.
4. **ML-Agents.**
   - Пакет `com.unity.ml-agents`, Python 3.10 + `mlagents==1.1.0`.
   - Агент и сцена, standalone-сборка для обучения, обучение.
   - Импорт `.onnx`, проверка инференса. Коммит.
5. **3D-модели.** Заменить примитивы (например, Kenney CC0: персонажи, данжен, космос), настроить анимации. Коммит.
6. **Скриншоты** всех сцен в Play Mode (Unity-окно в фокусе или ручной Step).
7. **Отчёт.**
   - Заполнить шаблон: титульник, разделы 1–4, картинки к каждому упражнению, таблица коммитов.
   - Экспортировать в PDF с правильным именем.
8. **GitHub.** Создать публичный репозиторий, выполнить `git push`, вставить ссылку в раздел 2 и пересобрать PDF.
